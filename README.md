# 🛒 FreshCart Sales Analytics

**Turning supermarket sales data into actionable business insights.**

An end-to-end data analytics project using Python and Microsoft Excel to explore supermarket revenue, product categories, promotion performance, festival demand, and seasonal trends.

## 🔗 Google Colab Notebook

[Open the FreshCart Analysis Notebook](https://colab.research.google.com/drive/1tv8mdAdua9swzka1WiAgGiVap7ISg_I_?usp=sharing)

## 🛠️ Tech Stack

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Google Colab
- Microsoft Excel, PivotTables and PivotCharts

## 📊 Key Analysis

- Revenue by product category
- Store sales performance
- Promotion campaign comparison
- Festival demand analysis
- Seasonal product performance
- Monthly sales trends

## 📁 Deliverables

- Python EDA notebook
- Raw and cleaned datasets
- Excel analysis workbook
- Data visualizations and business insights

## 🎯 Project Objective

Discover meaningful sales patterns and support data-driven inventory planning, merchandising, and promotional decisions.

## 📌 Data Disclaimer

This project uses synthetic practice data for academic assessment. The results are illustrative and do not represent actual business performance.
